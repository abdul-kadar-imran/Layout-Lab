# 📖 About

Layout Lab is a responsive layout preview application built for frontend developers and UI/UX designers. It allows users to instantly visualize how a website appears across different screen sizes without switching browser windows or opening device emulators.

Whether you're building landing pages, dashboards, portfolios, or web applications, Layout Lab helps you verify responsiveness quickly and efficiently.

# 🎯 Why Layout Lab?

Testing responsive websites usually requires browser DevTools, multiple devices, or third-party emulators.

Layout Lab simplifies this workflow by providing an elegant interface where developers can preview layouts side-by-side, making responsive design testing faster and more intuitive.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/layout-lab.git
```

Navigate to the project

```bash
cd layout-lab
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
